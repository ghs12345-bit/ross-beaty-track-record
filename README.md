# Ross Beaty — 投资履历全景分析

Lumina Metals 董事长 **Ross Beaty** 历史投资履历的整合型可视化报告。

## 内容

- **`index.html`** — 单文件交互式 SPA 报告（离线自包含，无需联网），6 章节左侧栏导航：
  - **概览** — 核心指标与关键判断
  - **公司版图 · 总表** — 20 家公司汇总表（按 A/B/C/D 四类筛选）
  - **公司版图 · 指标卡** — A/B/C/D 四类公司明细指标卡
  - **资产地图** — 跳转入口（点击「打开资产地图 ↗」进入独立全屏地图）
  - **时间线** — 1978–2027 横向泳道图 + 下方 20 家公司指标卡（公司名 ↔ 指标卡锚点对应）
  - **交易与估值** — 退出模式与估值锚点
- **`Beaty_资产地图.html`** — **独立全屏资产地图**（255 KB，联网加载 ArcGIS World_Topo_Map 瓦片）：
  - header 三 KPI（49 矿点 / 20 公司 / 20 当前名下）
  - 左侧筛选栏：state-switch「全部 / 当前名下」+ 公司 / 国家 / 品种 三维 tab + 两级可展开列表 + 多选 chip
  - 右侧：6 阶段筛选（生产/建设/可研/勘探/关闭/未分类）+ 聚合点开关
  - 右下角动态图例（金 19 / 铜 16 / 银 8 / 风电 3 / 镍 1 / 地热 1 / 水电 1）
  - 重叠点环形抖动 + 四段式 popup（基本信息 / 所有权 / 资源·品位 / 品种·位置）
- **`Beaty_Company_Asset_Ledger.xlsx`** — 7-sheet Excel 台账（公司 / 资产 / 事件 / 估值等）

## 数据口径

- 收录范围：Beaty 历史拥有 / 控制 / 参股的全部公司，分 A（创立并控制）/ B（2005 一拆四）/ C（非矿业）/ D（仅董事或小比例参股）四类。
- 当前名下（3 家）：Pan American Silver（创始人 / 名誉董事长）、Equinox Gold（董事长至 2026）、Lumina Metals（现任董事长）→ 共 20 项资产。
- 资源量 / 储量均为交叉验证后的口径，冲突项单独标注裁定依据。
- 裁定优先级：监管备案(SEC/SEDAR+) > 联合新闻稿 > 买方公告 > 公司 IR > 权威媒体。
