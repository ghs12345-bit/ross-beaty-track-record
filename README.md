# Ross Beaty — 投资履历全景分析

Lumina Metals 董事长 **Ross Beaty** 历史投资履历的整合型可视化报告。

## 内容

- **`index.html`** — 单文件交互式报告（离线自包含，无需联网）：
  - 公司版图（20 家，A/B/C/D 四类）
  - 资产分布交互地图（49 项资产，Leaflet 引擎 + 内联大陆轮廓，无第三方瓦片）
  - 投资时间线（泳道图，创立/退出/存续）
  - 公司总表 + 资产明细表（含国别、品种、资源量/品位/含金属量）
  - 估值锚点、交易事件定案表
- **`Beaty_Company_Asset_Ledger.xlsx`** — 7-sheet Excel 台账（公司/资产/事件/估值等）

## 数据口径

- 收录范围：Beaty 历史拥有/控制/参股的全部公司，分 A（创立并控制）/ B（2005 一拆四）/ C（非矿业）/ D（仅董事或小比例参股）四类。
- 资源量/储量均为交叉验证后的口径，冲突项单独标注裁定依据。
- 裁定优先级：监管备案(SEC/SEDAR+) > 联合新闻稿 > 买方公告 > 公司 IR > 权威媒体。
